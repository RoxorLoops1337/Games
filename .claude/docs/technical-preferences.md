## Naming Conventions

- **Classes**: PascalCase (e.g., `PlayerController`)
- **Variables**: snake_case (e.g., `move_speed`)
- **Signals/Events**: snake_case past tense (e.g., `health_changed`)
- **Files**: snake_case matching class (e.g., `player_controller.gd`)
- **Scenes/Prefabs**: snake_case matching the file (e.g., `player_controller.tscn`)
- **Constants**: UPPER_SNAKE_CASE (e.g., `MAX_HEALTH`)

## Performance Budgets

- **Target Framerate**: 60 fps (management screens may idle)
- **Frame Budget**: 16.6 ms on a mid-range 2022 Android phone browser
- **Draw Calls**: keep low via cached, batched tile modules (target under 200 per frame)
- **Memory Ceiling**: stay within a mobile browser tab budget; measure on device
