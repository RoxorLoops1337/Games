# Art direction and provenance

All raster illustrations were newly generated with the built-in image-generation tool for this project. No Roguebook illustrations or other game assets were extracted. The generated PNG masters remain in the creating session's generated-images directory; the project uses optimized WebP copies, preserving alpha where supplied. Sprite and card atlases are positioned with CSS. Font `title.woff2` is the existing repository's Cinzel title font from `tools/nrfh_trailer/fonts/Cinzel900.woff2`.
