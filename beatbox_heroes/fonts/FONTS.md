# Fonts

- PressStart2P.ttf, Silkscreen*.ttf: pixel fonts of the 2D game and the dev menu (OFL).
- Fredoka-500.woff2, Fredoka-700.woff2: rounded display font of the 3D UI (r3/theme3d.css). Latin subset
  (ASCII, Latin-1, common punctuation). Copyright 2016 The Fredoka Project Authors, SIL Open Font License 1.1,
  full text in Fredoka-OFL.txt. Source: Google Fonts (fonts.google.com/specimen/Fredoka).
- Fallback chain in the 3D UI: Fredoka, "Trebuchet MS", system-ui, sans-serif.
