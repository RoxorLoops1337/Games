# RUSTGRIFT
A hand-inked deckbuilding roguelike where every encounter can be fought or talked out of.
Run `play.bat` (starts a local server and opens the game), or open `index.html` directly.

- 3 characters, 2 acts, branching maps, 2 bosses, 20+ enemies
- Two decks: BATTLE cards and TALK (negotiation) cards
- Shops, campfires, events, grafts (relics), upgrades, card removal, autosave/continue
- Keys: click/drag cards, 1-9 select card, E end turn, Esc menu, right-click cancel

## Art layers (all procedural, each in its own file)
art_humans / art_creatures (characters), art_env (backdrops), art_ui (cards, HUD), art_icons, art_fx (particles, post), art_scenes (map, title, menus).
Lab pages: lab_humans.html, lab_creatures.html, lab_icons.html. Sprite/icon/backdrop overrides: see assets/AI_PROMPTS.md.

## Visual identity
The game now follows the RoxorLoops & Jasmin look (see reference/STYLE_BIBLE.md): bubbly sticker outlines, lime/pink/cyan palette, chibi heroes (Roxor, Bass, Jasmin), spray-paint concert backdrops, marker doodles.
